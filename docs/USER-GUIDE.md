# Undiyal (உண்டியல்) – Family Finance & Records

An *undiyal* is the little savings box many of us had as children. Undiyal is a personal, goal-based family finance tracker that runs entirely in your web browser. It is a single file, `Undiyal.html`. There is nothing to install and no account to create, and your data never leaves your computer.

## What it does

- Tracks what you own (mutual funds, stocks, PF, PPF, deposits, savings) and which goal each holding is for.
- Shows how far along each goal is (retirement, children's education, house, emergency fund and so on), how much you need to invest each month, and whether the mix of equity and debt suits the time left.
- Keeps a history of your total savings through monthly snapshots.
- Tracks your loans (EMIs, principal still owed and interest still to pay) so net worth stays accurate.
- Stores important family details (insurance, bank accounts, deposits, ID documents) with scanned documents attached, and reminds you of upcoming premiums, maturities and expiries.
- Creates a simple, plain-language summary to share with your family, or a detailed report for an adviser with the sections you choose (**Reports ▾** at the top), as an HTML file or PDF.

## Where it works

- **Works:** computers (Windows, Mac, Linux) in Chrome, Edge, Firefox or Safari, and Android phones in Chrome.
- **Does not work on iPhone or iPad.** The Files app only previews HTML files without running them, so you see a blank page or a "can't run here" message, and no iPhone browser can open a file saved on the phone. Use a computer or an Android phone instead.

## Your data and privacy

- **Everything is kept in one JSON file on your computer or phone** (for example `undiyal-data.json`). The tracker never uploads anything.
- **Chrome and Edge on a computer, and Chrome on Android,** save every change straight to that file and remember which file you used, so you can continue with one click next time. Only a reference to the file is remembered, never its contents. Next time, click **Continue with undiyal-data.json** (or press Enter) and allow access when Chrome asks. Browsers always need this one click for a file opened from your computer or phone.
- **Firefox, Safari and older phone browsers** cannot write to files. A bar at the bottom shows "Unsaved changes" with **Save data**, which downloads `undiyal-data.json`: replace your old file with it (the browser may name a repeat download `undiyal-data (1).json`; next time, open the newest one). Until you save, your changes are kept in this browser on this device, so they survive closing the tab; next time the start screen offers to recover them. Snapshots and documents are inside that file.
- **Set a passphrase** (Settings → Your data file) if the file holds personal details or documents. The whole file is then encrypted (AES-256). If you forget the passphrase, the file cannot be opened.
- **Header buttons.** Chrome and Edge: **Save data** until you have chosen a file, then only **Back up data** (every change already saves to your file). Firefox and Safari: **Save data** and **Back up data**. On a phone they are in the ⋯ menu.
- **Back up data** downloads a dated copy, `undiyal-backup-YYYY-MM-DD.json` (year first, so backups sort in date order), and you stay on your current file. Keep it somewhere other than this computer, such as a USB drive or a cloud folder. The dashboard reminds you if you have not backed up in 30 days, and Settings → Your data file shows the date of your last backup. **Save as new file** (Chrome and Edge, in Settings) is different: it moves your work to a new file.

## Getting started

1. Open `Undiyal.html` on a computer in Chrome, Edge, Firefox or Safari, or on an Android phone in Chrome (not iPhone or iPad). Click **About** (top left) for a plain-language introduction you can show your family.
2. The start screen has a **Preferences** bar at the top: **Language** (changes the start screen and the setup wizard straight away), **Number format** and **Currency symbol** (used when you start a new file; a file you open keeps its own settings). Below it are two cards:
   - **Left:** **Continue with undiyal-data.json** (or press Enter) if you have used Undiyal before in this browser, or **Open your data file** (click the box or drop your JSON file onto it). **Open a different file** and **Forget this file** are here too.
   - **Right, Start something new:** **Start the setup wizard**, or **Try it with sample data** to look around first. The sample includes SIPs and contributions, plans that pay from a set age and an annuity ladder, so every page has something to show. Sample data is never saved unless you choose Save data.
3. The **setup wizard** first shows a short note, once per data file: Undiyal is not financial advice, the figures are estimates, and your data stays on your device. Click **OK, got it** to continue. The **Back** / **Next** bar stays at the bottom of the screen on every step, and **Next** names the step that follows (for example **Next: Goals**). It then takes seven steps:
   1. **Preferences:** language, number format and currency symbol (filled in from the start screen). Everything else, such as expected returns, the equity level for long-term goals, reminders, dashboard charts, theme and text size, keeps sensible defaults; change it any time in **Settings** after setup.
   2. **About you (optional):** names and ages for you and your spouse, and children's names and birth years. Ages fill in goal years and are shared with the retirement calculator (change them in either place); names show whose each holding is.
   3. **Goals:** add what you are saving for. To start quickly, pick a **starter pack** (Single, early career · Couple, no children yet · Family with young children · Nearing retirement): it adds the usual goals with example amounts, and years worked out from the ages in step 2. Packs with children's goals add one education and one marriage goal for each child entered in step 2 (the card shows how many); with no children entered, one child is assumed. Or add goals one at a time from the **goal library** (grouped as Life, Safety, Children, Big purchases and Lifestyle: retirement, emergency fund, parents' medical fund, children's education, postgraduate study and marriage, house down payment, renovation, car, vacation, career break and starting a business); each opens a small helper in a pop-up, such as levels to pick from, months of expenses, or a share of the home price plus stamp duty and registration (7% by default; change it to your state's rate), and shows what the cost becomes by the goal year; press Enter or Add this goal. **+ Your own goal** at the top of the library is for anything else. Every helper has an editable Name, and for children's goals the child is picked for you: the first child who does not have that goal yet. The step has two cards at the top, **Start with a set of goals** and **Or add goals one at a time** (the goals as pills, grouped Life, Safety, Children, Big purchases and Lifestyle); choosing in one folds the other away (click **Show** to open it again). Once you scroll past the two cards, a slim two-line bar slides in at the top with the goal pills (or, if you picked a starter pack but have not added it, the pack with **Add these goals** and **Change**), so you can keep adding without scrolling back up; it hides again when the cards are back in view. Below them, **Your goals** are editable rows (goal, cost today, cost when due or corpus, year, inflation) with a total at the bottom; on a phone each goal is two lines, in alternating colours. new goals are scrolled into view and highlighted. For retirement, the pop-up asks for the **Corpus at retirement** (left empty for you to fill), the retirement year (from the ages in step 2) and inflation. If you are not sure of the corpus, **Not sure? Work it out with the calculator** opens the corpus calculator in the same pop-up; **Use ₹X as the corpus** brings the amount back to the form, and nothing is added until you click **Add this goal**. On a retirement card, **Not sure? Calculate corpus** and **Recalculate** open the calculator in a pop-up for that goal. All amounts are examples to change to your own. Each row has **Cost today** and **Cost when due**: you type one, and the other is worked out (shown in a grey box). For most goals you type today's cost; for retirement you type the corpus you need at retirement, or use **Not sure? Calculate corpus**. If you are continuing a plan made in an earlier year, tick that option and enter the costs as you worked them out then; the tracker adds inflation up to today.
   4. **Holdings:** three ways in: **Import CAS statement** (mutual funds and shares; *Don't have it yet? How to get it* explains how to get one), **Upload holdings CSV** (with a template to download) and **Type them in**. While a statement or CSV is open, the step shows only that card. A statement is read, then reviewed on one screen (names you can shorten, New / Update for each holding, the statement's total checked) and added with one click. After that, **Statements and files added** lists each one (type · whose · how many holdings), with **+ Import another statement** (for example your spouse's, or a CAMS / KFintech one), **Download holdings CSV** / **Upload holdings CSV** to change many in Excel, and **+ Add holding**. After an import the page goes back to the top, where the message and the list are, and the bottom bar also has **+ Import another statement**. Added holdings are highlighted in **Your holdings**, which has an **Owner** column when more than one person owns holdings. While a statement is open, the bar at the bottom carries its main button (**Read statement**, then **Add N holdings**), and long reviews show the button at the top as well. If you run setup again, the step opens on your existing holdings with a note on how to update them. **Back** inside this step goes to the previous screen (review → read → the three ways in) before going back to Goals.
   5. **Goals for your holdings:** a pop-up first asks two things: **Suggest a goal for each holding?** (holdings that already have a goal keep it) and **Do you put money in every month or year?** If you say yes to SIPs, a list of your schemes opens with an amount and how often for each (funds, PF and PPF first; shares, ETFs, FDs and bonds under *Usually no SIP*; grouped by owner; a search box for long lists; *Download CSV* / *Upload CSV* for many at once; tick *I raise some of these every year* to add a step-up for each, by % or a fixed amount). On the page, suggested goals come first, marked **Suggested** with a **Keep** button; pick another goal or *Split across several goals…* to change one. A coloured bar at the bottom shows how many suggestions are left (**Review**, **Keep all**, **Clear them**) and turns green when every holding has a goal; its button reads **Keep N suggestions and continue**, or **Next: Loans**. If you said yes to SIPs but entered none, Next asks once whether to add them now. Holdings without a goal are allowed.
   6. **Loans (optional):** add your loans, or click *I have no loans*.
   7. **Finish:** choose where to keep your data file (Chrome and Edge), or let it download (other browsers). This opens the dashboard and saves your first snapshot. Nothing asks for a file before this step; until then your progress is kept on this device.

## Editing

**Moving around:** on a computer, scroll up a little anywhere on a long page and a slim bar with the tabs (plus **↑ Top**, and **Save data** when there are unsaved changes) slides in at the top; it hides again when you scroll down. On a phone the tabs sit in a bar at the bottom of the screen — **Home · Holdings · Goals · Important · More** — and **More** holds the rest (SIPs & contributions, Loans, Corpus, History, Settings) along with Search, the reports and Save data. **Search** (the box in the header, the 🔍 button on a narrow window, or **Ctrl/⌘ K**) finds any tab, holding, goal, loan or Important section by name and takes you straight to it; picking a holding or goal opens it for editing. The header also shows the open file: a dot that turns amber when there are unsaved changes, the file name (shortened with … if it is long — hover for the whole name), and a **🔒 Passphrase / 🔓 Set passphrase** pill that tells you whether the file is protected and lets you protect it. While the file is saved the dot says so on its own; a message such as *Saving…* or *Unsaved changes* appears beside the name only when there is something to report. The header buttons **☀ Light / ☾ Dark / ◐ Auto** (theme; Auto follows your device) and **A Text size** (A, A+, A++) show what they do; click to change.

Holdings, Goals and each Important section are read-only until you click **Edit**. Changes save as you type. **Done** keeps them; **Cancel** puts back everything as it was when you clicked Edit (with Undo, in case you cancel by mistake).

## Reading your dashboard

- **The header** has three numbers: **Saved so far** (with the share of what your goals would cost if you paid for them **today**: like with like; point at ⓘ for a plain explanation), **Needed by the goal dates** (with the cost in today's prices) and **Invest each month** (or **Invest more each month**, with "on top of ₹X a month already going in", once you have entered regular investments), then a progress bar and one line on what your savings grow to by the goal dates. **Show the details** has the rest (what falls due within 5 years, in 5–15 years and later, the share of today's cost already saved) and *How is this worked out?*.
- **What needs you** is one card with two parts: **Your next steps** lists up to three things worth doing now, for example a goal that is far behind, money not yet assigned to a goal, the amount to invest each month (or as a lump sum or yearly), or goals to rebalance; **Reminders** holds the checks (premiums due, values to update, a backup to make). The card's heading shows how many of each — a plain count for the steps and a **6 Reminders** badge that turns red when something is urgent — and **Hide** folds the whole card away (**Show** brings it back). When there is nothing to do at all, the heading shows a ✓.
- **Each goal's label** says where it is heading: *On course*, *Almost there*, *Getting there*, *Early days*, *Not started*, or *Far behind* (a goal less than 2 years away running out of time). A goal card shows how much of the target is saved now, and a line such as "Your current investments will reach 106% of the target by Mar 2048": how far today's savings get on their own by the goal date.
- **Still to cover** is the part of your goals that today's savings won't reach on their own, even after growing.
- **SIPs & contributions:** in the **SIPs & contributions** tab (or the setup wizard, the Add holding form, or the holdings CSV), each holding can have a **SIP or contribution**: an amount and how often (every month, quarter, 6 months, year, or every N months), for a SIP, PPF, RD or your PF contribution. Undiyal adds it to each goal's projection using the holding's goal split, growing at that holding's expected return, and then shows only the **extra** you need: "Already investing ₹17K a month · invest ₹12K more a month". Without regular investments entered, **Monthly needed** is the total to invest each month, including what you already put in.
- **Monthly needed / Invest more each month** is worked out per goal; a goal that is ahead does not make up for one that is behind.
- **Explain this page** (next to the tabs, or in the ⋯ menu on a phone) gives a short guided tour of the Dashboard, Holdings, Goals, Loans, Corpus and Important tabs, using your own numbers. With no data yet, it can show the tour with sample data without saving anything.

## Family members and joint holdings

Each holding has an **owner**: you, your spouse, a child, or **Joint**. Goals and the Dashboard always use the whole family's money together. The owner only records whose name a holding is in.

- **Importing statements for two people:** import each person's CAS one after the other. Undiyal reads the name and PAN printed on the statement and asks **Whose statement is this?** the first time. If that name matches a family member's name, or their initials (for example *KA* for *Kumar Aravindh*), entered in About you, that person is chosen for you; you can change it. Statements that print the PAN masked (for example *[AKXXXXXX6F]*) are recognised the same way, and remembered by the masked PAN. Holding names printed in capitals are shortened and tidied (*DABUR INDIA LIMITED* becomes *Dabur India*). After that it recognises the statement by PAN, using a one-way fingerprint; the PAN itself is never stored. Holdings are matched only within the same person, so a fund you both hold stays as two separate holdings.
- **Holdings tab:** with more than one owner, a row of buttons (**Everyone · you · spouse · Joint**) shows each person's total and filters the list. In Edit holdings, each holding has an owner dropdown. **+ Add holdings ▾** offers three ways in: **Enter manually** (a short form), **Import CAS statement (PDF)** and **Upload holdings CSV**. The **⋯ More** button next to it has **Download holdings CSV** (the file to edit in a spreadsheet) and **Guided monthly update**. **Category (optional):** each holding can have a category inside its type, such as *Index funds & ETFs*, *PPF*, *Gold & silver*, or one you create (for example *Property*). Type it in the Category box (setup wizard, Edit holdings, or the Add holding form): pick from the list, or choose **+ New category…** and say what it **counts as** (Equity, Debt, Liquid or Other); picking a category also sets the type. The Holdings list columns are Holding, **Owner** (when more than one family member has holdings), Type, Category, Current value, Invested, Gain, Share and Goal split. What changed since your last snapshot is in the **History** tab (**Since your last snapshot**). In the Holdings list, the **Category** column shows it (grey text is Undiyal's guess when you have not set one), and the Type column shows a **🔒 Locked** badge for money you cannot take out quickly; in Edit holdings, **Can sell quickly** is under Type. Settings → **Categories** lets you rename, re-type or delete your own (deleting keeps the holdings). The four types stay fixed because they drive growth and rebalancing. Without a category, Undiyal guesses one from the name. The CAS review screen has a **Category** column filled with Undiyal's guess (for example *Gold & silver* for gold ETFs and SGBs); change any before importing. The holdings CSV has a **Category** column, filled with your category or Undiyal's guess (as on screen). On upload, a guess left unchanged stays a guess; type a different name to set a category (a new name creates one under that row's type), or empty the cell to remove yours. **Editing one holding:** click its name, or the **Edit** button at the end of its row, to open a panel from the right with everything about it — name, owner, type, category, current value, invested amount, whether it can be sold quickly, the regular investment and its yearly rise — plus **Goal split**, which takes you to that holding's split. Nothing changes until you press **Save**; **Cancel** leaves it as it was, and **Delete** removes it (Undo works). Use **Edit holdings** instead when you want to run down the whole list changing values, as in a monthly update. **List · Split table** switches the view. Tick **Group by type** to show holdings under Equity, Debt, Liquid and Other, each with its count, total and share of savings (inside each type, holdings are sorted by category; a column sort, if you pick one, applies within each category); click a group to collapse or expand it. Click a column heading (Holding, Type, Current value, Gain, Share and so on) to sort: once for one direction, again to reverse, a third time to go back to your own order. Sorting works inside each group. The **Split table** has a Type column too, and its headings sort the same way, including each goal's % column (to see which holdings fund Retirement most) and **Split** (to find holdings that are not fully assigned). The grouping, collapsed groups and sort are remembered in your file. While you edit holdings, the list keeps the order it had on screen (without group headings), so rows do not move as you type; it re-sorts when you click Done. The Goal split column shows the largest goal, for example "Retirement 70% +1 more"; hover or click to see and edit the full split. Enter manually opens a short form. The name box suggests common investments (EPF, VPF, PPF, NPS, Sukanya Samriddhi, SCSS, NSC, KVP, Post Office schemes, FD/RD, SGB, gold, REITs, property and more), or you can type your own. It also has owner, type and liquidity (both guessed from the name, for example EPF is Debt and locked), current value, invested amount and goal. **Save and add another** keeps the form open for the next one. The new holding appears at the top of the list, highlighted, and Undo works.
- **Two PFs or PPFs:** add one holding for each person and set its owner, for example "EPF" (you) and "EPF" (spouse).
- **CSV:** the holdings CSV has an **Owner** column (use the names from About you, or Joint).
- **Reports:** the family summary and the detailed report show totals by person, and the detailed report adds an Owner column. Both include regular investments: the family summary says how much goes in each month and how much more is needed for each goal; the detailed report has a **SIPs & contributions** section and *Already investing* / *More needed* / *Growth needed* / *Assumed return* columns in its goals table.

## Your monthly routine

Use **Guided monthly update** (in the Holdings tab, or from the dashboard reminder). It has three steps:

1. **Statement (CAS):** import this month's CAS. NSDL / CDSL updates shares and mutual funds; CAMS / KFintech updates mutual funds only. The statement is read in your browser. You review it on one screen, where each holding shows **New** or **Update · ₹ change**, and add it with one click.
2. **Other holdings:** type new values for PF, PPF and deposits, or download the holdings CSV, update it in Excel and upload it back. Check each loan's outstanding principal (it is pre-filled from the EMI schedule).
3. **Review and save:** check what changed and save a snapshot.

A **snapshot** records all your values on a date and adds a point to the History chart. Saving again within your reminder period (30 days by default) asks whether to replace the last snapshot or add a new one. The snapshot bar at the top of Holdings appears only when values have changed or a snapshot is due; when everything is up to date it is hidden, and **Guided monthly update** is in the **⋯ More** menu next to Edit holdings.

## Good to know

- **On a phone,** tables become cards, buttons are larger, and About, text size, theme and downloads are under the ⋯ button at the top.
- **Amounts can be typed with commas** (45,00,000), and the amount appears in words under the field (₹45 lakh).
- **Deleting something shows an Undo** for 10 seconds.
- **Which version you have:** the version (for example 2026.11.13.1) and the data version are shown at the bottom of the start screen and at the top of About. If two computers behave differently, check that both have the same version.
- **About** (top left) opens a short guide in a pop-up, including how to get your CAS. The same guide is in the CAS import box under *How do I get these statements?*
- **Alerts on the dashboard** are coloured by importance, most important first: **red ⚠** needs action now (goal splits that do not add up to 100%, and dates due within 7 days or overdue); **amber ⚠** needs attention soon (a holding over your limit, values not updated, no recent backup, dates 8–30 days away); **blue ℹ** is for your information (a goal cost worked out in an earlier year). Alerts with several items have a **Show details** button. They are grouped:
  - one holding is too large a share of your portfolio;
  - premiums or maturities are due within 30 days;
  - values are out of date;
  - goal splits don't add up to 100%;
  - goal costs are years old;
  - no recent backup.

  You can dismiss most alerts: **Keep this cost** (an old goal cost; it comes back next year or if you change the cost), **Hide until next update** (a large holding; it comes back as soon as any holding value changes), **Done** (each premium, maturity or expiry date; yearly premiums come back next year) and **Remind me later** (out-of-date values or backup; 7 days). Goal-split alerts can only be cleared by fixing the split. **Settings → Dashboard alerts → Show hidden alerts again** brings everything back. Dismissals are saved in your data file.
- **Net worth** is your holdings minus the *outstanding principal* of your loans (not the future interest). Snapshots record loans as well, so History shows net worth over time.
- **Rebalancing** follows a simple rule of thumb: goals ten or more years away can hold more equity, and money moves towards debt as a goal gets closer. Only money you can take out (holdings not marked 🔒 Locked) is suggested for moving; when a goal's money is locked in (PF, PPF, ELSS), Undiyal suggests putting new monthly investments into equity or debt instead. For short-term goals (under 2 years) and emergency or liquid funds, Undiyal shows **Gap to close** (what is still missing and the amount per month, no growth assumed) instead of Monthly needed, and marks the goal **Far behind** when less than half is saved with a year or less to go, or less than a quarter with up to two years to go. It is guidance, not financial advice.

What you type yourself (goal names, fund names, notes) stays as you typed it. The start screen opens in the language you used last. ## Supported statements and files

### Getting your CAS

- **NSDL / CDSL CAS:** arrives by email automatically, at the email registered with your demat account. It comes every month if there were transactions, otherwise every six months. The password is usually your PAN in capital letters.
- **CAMS / KFintech CAS:** request it on camsonline.com (the "CAS – CAMS + KFintech" statement); mfs.kfintech.com and MF Central offer the same.
  1. Choose the detailed statement and the period.
  2. Enter your PAN and the email registered with your funds.
  3. Set a password.

  The PDF arrives by email within a few minutes.

- **CAS:** two kinds, recognised automatically:
  - **NSDL / CDSL CAS** (depository statement): shares, ETFs, bonds and mutual funds. Use this one if you hold shares. Its password is usually your PAN in capital letters.
  - **CAMS / KFintech / MF Central CAS:** mutual funds only (detailed or summary). Its password is the one you set when requesting it.

  The import has **two steps**: **1 · Read statement** (choose the PDF and type its password) and **2 · Review and add**. In step 2 everything is on one screen: a check that the holdings add up to the statement's total, then one row per holding with an **Import** tick, an editable **Name** (shortened for you, for example *Parag Parikh Flexi Cap* instead of *Parag Parikh Flexi Cap Fund - Direct Plan Growth*; the statement's full name stays underneath), Type, Category, Market value and **What happens**: *Add as new holding* or *Update* an existing one, with a tag (**New**, **Update · +₹ change**, or **Check the match** in red when the name is only a close match). A single button (**Add 2 new · update 3**) saves everything; nothing changes before you click it. Then the card closes, a message says what was added and updated, and those holdings are highlighted in the list. Updating keeps your existing name for that holding; the statement name is remembered so the next import matches it even if you renamed it.

  **Folio numbers** in the statement are saved to Important → Mutual fund folios (with the fund house), not shown in Holdings, and listed in the family summary. Untick the option on the review screen to skip this. The **statement PDF itself** is kept in Important → Account statements (CAS), one per statement type (NSDL / CDSL and CAMS / KFintech); importing a newer one replaces the older PDF. It stays password-protected, and PDFs over 3 MB are not stored. It is saved only when the import succeeds (at least one holding imported). To skip it, untick *Keep this statement…* under the password field or on the review screen; your choice is saved in your data file. Both password-protected and AES-256 encrypted PDFs are supported. Holdings that appear in both statements are matched by ISIN, so they are not counted twice.
- **CSV:** use **Download holdings CSV** (in **⋯ More**) to get the right columns: ID, Holding, Owner, Type, Category, Liquid, Current value, Invested, Regular amount, Every (months), Rises each year and one "% column" per goal. Keep the ID column as it is, and leave it empty for new holdings. Upload it back with **+ Add holdings ▾ → Upload holdings CSV**; you see every change before it is applied.

## Troubleshooting

- **"Saving files is not available" or a download every time:** your browser cannot write to files (Firefox, Safari or an older phone browser). Use Save data and replace your old file with the newest download, or use Chrome or Edge on a computer, or Chrome on Android.
- **"This file is not a PDF" or "Undiyal could not read this PDF":** the file is not the CAS statement itself (for example a web page saved as .pdf, a download that did not finish, or a bank or broker report). Download the CAS again from the email and choose that file.
- **The CAS shows no holdings:** check that it is an NSDL / CDSL, CAMS, KFintech or MF Central CAS and that the password is right, then use **Show extracted text** to see what was read.
- **A fund name looks cut short, or too long:** edit it in the Name box on the CAS review screen before adding, or later in Holdings → Edit holdings.
- **Blank page or "Undiyal can't run here" on iPhone or iPad:** iPhone and iPad are not supported. Use a computer or an Android phone.
- **The file won't open:** if it was encrypted, check the passphrase. Otherwise, try your latest backup.

## Opening files from older or newer versions

- Every data file records a **data version** (shown in About and on the start screen, next to the app version).
- **Older file:** Undiyal shows an **Updating your data file** screen before opening it, and runs four checked steps: (1) **save a copy of the original**, untouched and still encrypted if it was (`undiyal-before-update-YYYY-MM-DD.json`, in your downloads); (2) **update the data** on a copy in memory; (3) **check that nothing was lost**: the number of holdings, goals, snapshots and record sections and the total value must be the same, and the screen shows them; (4) **check that the updated file saves and opens** (for a protected file, it is encrypted and decrypted again). Each step gets a tick. If any step fails, Undiyal stops, says which step, and opens nothing; your original file is not changed. Click **Open my data** when all four have passed.
- **Newer file** (saved by a newer Undiyal): you can **Open read-only** to look at it. Nothing is saved; download the latest `Undiyal.html` to edit it.
